# 实测：Shape 没变，预测变了吗？

同一模型对同一批留出样本做两次预测。我们只交换两个输入列，不重新训练，也不更改任何一个样本的真实标签。两次调用都能运行，输入形状都是 `(111, 3)`；平均绝对误差（MAE，越低越好）却从 **42.156** 变为 **395.705**。

## 实验设计

[实验脚本](../examples/diabetes/study.py) 使用 scikit-learn 自带的 `load_diabetes` 数据集，无需下载。数据共 442 行，标签为一年后的疾病进展定量指标。用 `train_test_split(test_size=0.25, random_state=42)` 留出 111 行测试数据；`LinearRegression` 只在其余 331 行上拟合一次。选择 `bmi`（体重指数）、`bp`（平均血压）和 `s5` 三列原始特征，设置 `scaled=False`，不做额外缩放或调参。

| 调用 | 输入顺序 | 留出集 MAE | 与正确顺序预测不同的行数 |
| --- | --- | ---: | ---: |
| 对照 | `bmi, bp, s5` | 42.156 | 0 / 111 |
| 换列 | `bp, bmi, s5` | 395.705 | 111 / 111 |

两组首先用 pandas 按名取列，再用 `.to_numpy()` 丢弃列标签。对于前两列的模型系数 $w_1,w_2$ 和输入值 $x_1,x_2$，交换位置引起的预测差为 $(w_1-w_2)(x_2-x_1)$。因此差值的大小既受特征量纲影响，也与拟合得到的权重有关。表中只把绝对差超过 `1e-8` 的预测计为变化。

## 复现

在仓库根目录运行。第一条命令只分析源码，不需要安装科学计算库；第二条才执行这个固定的实验脚本，需要已有的科学计算环境。

```sh
python -m featureguard examples/diabetes/study.py
python examples/diabetes/study.py
```

静态分析应输出 `2 prediction sites, 1 verified, 1 diagnostic`：对照组通过，换列的 `predict` 处报 `FG001`，同时给出训练选列和预测选列的位置。此时退出码为 **1**，表示发现问题，不表示扫描失败。数值结果实测环境：Python 3.12.10、scikit-learn 1.7.2、pandas 2.3.3、NumPy 1.26.4。

## 如何解读

本例说明仅检查特征数量或运行是否抛异常会漏掉一种真实错误，不代表交换两列一定会增大误差。系数相同、样本两列相同或模型对交换不敏感时，数值差可能为零。FeatureGuard 报的是可证明的**输入列顺序不一致**，不是对预测损失的估算。该实验使用单一划分演示软件错误，不用于模型选型或临床判断。
